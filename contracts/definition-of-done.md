# Definition of Done

A task is complete only when:

- the requested behavior is implemented;
- acceptance criteria have been verified;
- relevant tests pass;
- no known failure is hidden;
- error and empty states have been considered;
- security and input validation have been reviewed;
- logging and observability have been considered when relevant;
- documentation and examples have been updated when needed;
- the diff has been reviewed;
- the result is reported with files and evidence.
